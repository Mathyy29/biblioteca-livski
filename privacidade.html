Política de Privacidade

1. Introdução

A Biblioteca Livski valoriza a privacidade de seus usuários. Esta Política de Privacidade apresenta as informações sobre os dados que podem ser fornecidos durante a utilização do site e como essas informações são utilizadas.

2. Dados coletados

O site pode receber informações fornecidas voluntariamente pelo usuário, como nome, endereço de e-mail e mensagens enviadas por meio dos canais de atendimento disponíveis.

3. Utilização dos dados

Os dados fornecidos são utilizados para possibilitar o atendimento das solicitações, responder às mensagens enviadas pelo usuário e permitir o funcionamento dos recursos disponibilizados pelo site.

4. Armazenamento local

Para o funcionamento do carrinho de compras, o site pode utilizar o armazenamento local do navegador, conhecido como localStorage. Essas informações ficam armazenadas no próprio dispositivo do usuário e são utilizadas para manter os produtos selecionados durante a navegação.

5. Compartilhamento de informações

As informações fornecidas pelos usuários não são vendidas ou comercializadas. O compartilhamento de dados poderá ocorrer somente quando necessário para o funcionamento dos serviços ou em situações previstas pela legislação.

6. Segurança

São adotadas medidas adequadas para evitar o acesso ou uso indevido das informações fornecidas. Entretanto, nenhum sistema eletrônico está completamente livre de riscos de segurança.

7. Direitos do usuário

Nos termos da Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018), o usuário possui direitos relacionados aos seus dados pessoais, incluindo o acesso às informações sobre seu tratamento, a correção de dados incompletos ou incorretos e os demais direitos previstos na legislação.

8. Alterações na política

Esta Política de Privacidade poderá ser atualizada sempre que necessário. Eventuais alterações serão disponibilizadas nesta página.

9. Finalidade do site

A Biblioteca Livski é um projeto desenvolvido para fins educacionais. As informações apresentadas no site têm finalidade exclusivamente relacionada ao funcionamento e à apresentação do projeto.

10. Contato

Em caso de dúvidas sobre esta Política de Privacidade, o usuário poderá utilizar os canais de contato disponibilizados no site.
